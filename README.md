# Firefighter Alarm System

Enhance your FiveM server with a realistic firefighter alarm system.

## Features

- Alarm activation
- Firefighter readiness
- Magnet shield activation

## Requirements

- FiveM server
- ESX Framework
- MySQL

## Installation

1. Download the script from the releases page.
2. Extract the files into your FiveM server's resources folder.
3. Add `start ff_alarm_system` to your server.cfg file.

## Usage

- Players can activate the alarm by approaching a fire station.
- Firefighters can mark themselves as ready for duty using the E key.
- Firefighters can activate a magnet shield on their vehicle using the G key.

## Configuration

The script can be configured in the `config.lua` file. You can adjust the alarm duration, cooldown, fire station locations, and magnet shield settings.
